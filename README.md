# 🧊 L3DC - Little 3D Community

**Little 3D Community (L3DC)** é um projeto desenvolvido como parte da disciplina de Dispositivos Móveis da **Fatec Indaiatuba**. O objetivo é criar uma plataforma dedicada à impressão, funcionando como uma pequena vitrine para a postagem de produtos e projetos desenvolvidos através de impressão 3D.

O aplicativo permite documentar suas criações, armazenar links e descrição dos modelos. No momento ele não permite compartilhamento, somente o acesso pela aplicação.

## 🚀 Tecnologias

Este projeto utiliza o que há de mais moderno no ecossistema mobile atual:

- **[React Native](https://reactnative.dev/)** - Framework para apps nativos.
- **[Expo](https://expo.dev/)** - Ecossistema para facilitar o desenvolvimento e testes.
- **[TypeScript](https://www.typescriptlang.org/)** - Linguagem que adiciona tipagem estática ao JavaScript.
- **[NativeWind](https://www.nativewind.dev/)** - Implementação do Tailwind CSS para React Native, garantindo uma estilização ágil e responsiva.

## 📦 Instruções de Instalação

Siga os passos abaixo para configurar o ambiente e rodar o projeto localmente:

### Pré-requisitos
- **Node.js** (versão LTS recomendada).
- **Git** para clonar o repositório.
- Aplicativo **Expo Go** instalado no seu celular ([Android](https://play.google.com/store/apps/details?id=host.exp.exponent) / [iOS](https://apps.apple.com/app/expo-go/id982107779)) ou um emulador devidamente configurado.

### Execução passo a passo

1. **Clonar o Repositório:**
   ```bash
   git clone [https://github.com/vicenzodev/L3DC.git](https://github.com/vicenzodev/L3DC.git)

2. **Entrar na pasta do projeto:**
   ```bash
   cd L3DC

3. **Instalar as dependências:**
   ```bash
   npm install
   
4. **Iniciar o Expo:**
   ```bash
   npx expo start

5. **Acessando o App**
   
   Após rodar o comando acima, um QR Code aparecerá no terminal:

   Abra o aplicativo Expo Go no seu celular.

   Escaneie o QR Code.

   O app será carregado e estará pronto para uso.
